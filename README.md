# 一番星 ICHIBANBOSHI · 制作人名片（P名刺）设计平台

面向偶像文化与动画游戏爱好者的双栖制作人名片（P名刺）设计平台：支持模板快速预填、极简表单/自由画布双模编辑、全可编辑区域自由材质与特种纸张定制、Three.js WebGL 真实物理材质 3D 预览、Phygital 实体+H5 双栖名片，以及印前 8 项校验与高清 PDF / PNG / JPG / SVG / 专色工艺版导出。
